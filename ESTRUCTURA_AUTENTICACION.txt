🎯 CÓMO FUNCIONA LA AUTENTICACIÓN

1️⃣  INICIALIZACIÓN
   └─ AuthProvider envuelve toda la app
   └─ useAuth() está disponible en todos los componentes
   └─ Los datos de prueba se cargan automáticamente

2️⃣  LOGIN
   └─ Usuario entra email + contraseña
   └─ Se valida contra localStorage['users']
   └─ Se guarda sesión en localStorage['user']
   └─ Se redirige al dashboard

3️⃣  REGISTRO
   └─ Usuario llena formulario de registro
   └─ Se validan todos los campos
   └─ Se verifica que el email no exista
   └─ Se agrega nuevo usuario a localStorage['users']
   └─ Se inicia sesión automáticamente

4️⃣  PROTECCIÓN DE RUTAS
   └─ ProtectedRoute verifica if (isAuthenticated)
   └─ Si no está autenticado: redirige a /login
   └─ Si está autenticado: muestra el contenido

5️⃣  LOGOUT
   └─ Botón en el sidebar
   └─ Limpia localStorage['user']
   └─ Redirige a /login

🚀 PRÓXIMOS PASOS

Para integrar con un servidor real:

1. Modificar src/contexts/AuthContext.jsx
   └─ Cambiar login() para llamar a API
   
2. Implementar hash de contraseñas
   └─ Usar bcrypt o similar en backend
   
3. Implementar JWT o sesiones
   └─ Guardar token en lugar de usuario
   
4. Agregar verificación de email
   └─ Enviar enlace de confirmación

5. Implementar "recordar sesión"
   └─ Usar refresh tokens
